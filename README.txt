Julie Anniversary Website
=========================

How to use
----------
1. Extract the ZIP or keep this folder as-is.
2. Keep the folder structure intact:
   index.html
   style.css
   script.js
   assets/music.mp3
   assets/reco.m4a
   gift/g (1).jpeg ... gift/g (96).jpeg
3. Put your photos inside the gift folder using these exact names:
   g (1).jpeg
   g (2).jpeg
   ...
   g (96).jpeg
4. Optional: add a hero image at:
   gift/i17.png
5. Double-click index.html to open the website.

Where to edit text/details
--------------------------
Open script.js and edit the top section marked:

EDIT HERE

You can change:
- girlfriend name
- your name
- PIN
- music and voice note paths
- letter
- 9 reasons
- coupons
- timeline month/photo mapping

Notes
-----
- The website works as a local static website.
- It does not need npm, React, a backend, a server, or internet.
- Missing photos will show soft placeholders instead of breaking the page.
- Missing music or voice note files will show a small message and the website will continue.
